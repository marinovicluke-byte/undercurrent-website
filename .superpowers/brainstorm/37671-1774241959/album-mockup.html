Design Notes

  • Page flip animation — When case studies are added, clicking tabs triggers a 3D CSS perspective page-curl. Pages fold over like a real album with shadow and depth.
  • Ocean wave — Animated canvas waves flow across the background (similar to WaterCanvas on other pages). Inside the album, subtle SVG waves drift at the bottom.
  • Tab edges — Right-side tabs act as dividers. Hovering extends them slightly. Active tab highlighted with sage border. On mobile, tabs shrink but remain functional.
  • Coming Soon state — Minimal, centered message with book icon. When you add studies, each page will have: client name, industry, problem, solution, key metrics, and a quote.
  • Mobile — Album scales down, tabs remain accessible. Page flip works via swipe gesture on touch devices.
  • Brand consistent — Uses Cormorant headlines, DM Sans body, DM Mono labels, sage accents, charcoal background, ambient gradient blurs.
