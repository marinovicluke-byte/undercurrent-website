# UnderCurrent — Design Context

## Design Context

### Users
Small business owners in Australia (Melbourne-focused) who are time-poor and tech-aware but not technical. They're evaluating whether to trust an automation agency with their operations. Context: they arrive via Google search, AI search (ChatGPT, Perplexity, Google AI Overviews), or referral. Skeptical of hype, need to be convinced quickly with specifics. Job to be done: understand what UnderCurrent does, whether it applies to their business, and book a call with minimal friction.

### Brand Personality
**3 words:** Calm, Precise, Grounded.

Voice: Direct operator, not a salesperson. Short sentences. No exclamation marks. No buzzwords. Specific metrics. Dry wit. Em-dashes for parentheticals.

Emotional goal: visitors should feel like they've found the competent, no-nonsense agency they've been looking for — not excited, reassured.

### Aesthetic Direction — v2 (current)
**Dark editorial with teeth.** Dark charcoal base (`#121210`), large Space Grotesk display type, rounded 14px cards with **hard offset accent shadows** (`4-6px 4-6px 0 0 var(--accent)`). No ambient glows or gradient decoration — the pop-shadow IS the visual accent.

**Palette (same as before, rebalanced):**
- Blue `#6A8DAD` / light `#8AAEC8` — informational, default primary.
- Sage `#8FAF9F` / light `#A8C4B8` — positive, "after", outcomes.
- Orange `#E07A55` / light `#E8967A` — warnings, "before", single-spot emphasis only, never primary.
- Off-white `#FAF9F5`, charcoal `#1C1C1A`, deep `#121210`.

**Type:** Space Grotesk display (weights 400/500), Satoshi body. Max 2 weights per typeface per page. SF Mono confined to stat numerals and section-number eyebrows — never as a decorative "technical" voice on every label.

**Layout:** `maxWidth: 1280`, left-aligned, `var(--page-pad)` horizontal padding (30px mobile, 88px desktop). Black hero → charcoal body per section.

### The Six Design Principles

1. **One idea per accent, one accent per section.** Blue for Why/Information, Sage for Shift/After/Positive, Orange for Before/Warning or single highlight only. Mixing all three in the same viewport = noise.
2. **Hard offset shadow replaces soft accent blur.** `6px 6px 0 0 var(--accent)` — not `0 12px 40px -22px rgba(accent, 0.45)`. Same visual weight, opposite posture. This is the "teeth."
3. **Solid accent color replaces gradient text.** No `WebkitBackgroundClip: 'text'` on headings, no animated shimmer. A keyword gets one color swap, that's it.
4. **One radial glow per page.** Reserved for the closing CTA as an arrival moment. No ambient section-glows, no pulsing.
5. **SF Mono is for numerals and section numbers only.** Never as a decorative voice on tag labels.
6. **Glow-word restraint.** Max 1-2 styled keywords per heading. SEO/AIO keywords remain in the underlying H1/H2 text; visual emphasis is single, not scattered.

### What stayed from v1
- Palette, fonts, section numbering pattern (01-07 eyebrows)
- Rounded 14-16px cards (memory-confirmed UC pattern)
- `.uc-glow-word` class name (now solid color, not animated gradient)
- Marquee with reduced-motion support
- Video hero with reduced-motion fallback
- Copy voice, section order, SEO keyword placement

### Anti-references (AI-slop fingerprints to avoid)
- Gradient text on headings (`-webkit-background-clip: text` + linear-gradient).
- Animated shimmer or pulse on decorative elements.
- Glassmorphism — `backdrop-filter: blur()` on cards, panels, or buttons.
- Soft accent blur shadows — `box-shadow: 0 Npx Npx -Xpx rgba(accent, 0.X)`.
- Multiple radial gradient glows per page.
- SF Mono as the voice of every micro-label.
- Identical card grids (icon + heading + text, repeated 4-8 times).
- Hero metric layouts with gradient numbers.

### What makes it unforgettable
The combination of calm editorial typography + hard offset accent shadows. Everything else is familiar; the shadow pattern is the signature. The site should feel like a well-made object — not a glowing template.

### Design Principles (summary)
1. **Posture over polish** — hard offset shadows, solid color, clear type hierarchy.
2. **Earned confidence** — specific copy, real metrics, no decorative "AI feel."
3. **Controlled restraint** — orange and sage used sparingly. Blue is the default accent.
4. **Motion serves state** — hover feedback, section transitions. No ambient pulsing or shimmer.
5. **Hierarchy over decoration** — type does the heavy lifting; accent shadows frame, never illustrate.
