Design principles applied
1. One idea per section, one accent per idea. Blue for Revenue/Why, Sage for Time/Shift/After, Orange for Before/Warning only.
2. Hard offset shadow replaces soft accent blur. Same visual weight, opposite posture.
3. Solid accent color replaces gradient text. Removes the #1 AI-slop fingerprint.
4. One radial glow per page, saved for the closing arrival. Other sections earn attention through type and shadow only.
5. SF Mono confined to stat numerals and section numbers. Not used as a decorative "technical" voice.
6. Glow words reduced to 1 per heading. H1/H2 text still contains every SEO/AIO keyword; visual emphasis is single, not scattered.

What stayed identical
Palette, fonts, copy, section order, section numbering, marquee, video hero, 14px card radius (memory-confirmed UC pattern), eyebrow/label treatment, all JSON-LD and SEO keyword placement.
