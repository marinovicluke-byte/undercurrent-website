Under Next 16 Turbopack, the auto-detected root becomes the module resolution root. - **2026-04-28 `vercel env add NAME preview --yes` refuses to resolve to "all preview branches" non-interactively.** Even though the help text says omitting the branch argument means "all preview branches", `--yes` aborts with `git_branch_required`. ## CSS / Inline Styles

- **`clamp()` inside a CSS custom property fails silently in React inline style shorthands.** Using `--page-pad: clamp(42px, 6.8vw, 180px)` then `padding: '120px var(--page-pad)'` rendered at 0px left padding — no error, just silent fallback. Fix: put a simple px value in the variable (`--page-pad: 88px`) and handle responsiveness via `@media` override on `:root`. Potential lesson for other projects.

## Frontmatter conventions
- **2026-05-20 Article "last updated" frontmatter field is `dateModified`, NOT `updated`.** The live App Router route `app/blog/[slug]/page.js` reads `fm.dateModified` for both the OpenGraph `modifiedTime` (line 44) and the Article JSON-LD `dateModified` (line 155); it falls back to `fm.date` if absent. The legacy SPA component `src/views/Article.jsx` used `article.updated` — that field name is dead on the production route. Adding `updated:` to article frontmatter is a silent no-op: the schema keeps showing the original publish date. Fix is to use `dateModified: "YYYY-MM-DD"`. Potential lesson: when bumping an article's freshness signal, set `dateModified` in frontmatter and verify the live JSON-LD flipped via `curl … | grep dateModified` — don't trust the field name from the older component.

## Content quality workflow
- **2026-05-25 Audit-grade-retrofit pattern for glossary batches.** Workflow that surfaced the 1-of-1 angle without rewriting the whole batch: (1) write the batch end-to-end on a worktree, (2) ship to main, (3) honestly grade each entry on a 4-criteria rubric (citeable line, original example, contrarian stake vs consensus, declared UC opinion), (4) sort into 1-of-1 / differentiated / encyclopedia-shaped buckets, (5) retrofit only the encyclopedia-shaped ones with a first-principles contrarian take, (6) /humanizer pass, (7) re-grade. Batch-5 result: avg jumped 7.7 → 8.5 with surgical edits to 3 of 10 entries. The grading rubric works because it forces the question "what would a competitor's glossary refuse to write?" — that's where the 1-of-1 lives. Reusable for any client content where the first pass lands competent-but-forgettable. Potential lesson: don't audit during the write (slows the batch), audit AFTER shipping when you can read with fresh eyes. Cross-project candidate.

## Article blocks
- **2026-10-01 Look classes live on `<article>`, outside `.body`.** The block looks (`ucb-steps--*`, `ucb-data--*`, `ucb-qa--*`) sit on the article element; `.body` is a descendant. A selector written `.body .ucb-data--fit .ucb-data` never matches, silently: the fit table on desktop fell back to the rail's block cells and stacked. Write look selectors look-first: `.ucb-data--fit .body .ucb-data`. Found by reading computed `display` in Playwright, not by eye.
- **2026-10-01 `heroImage` is taken.** Six articles carry a legacy `heroImage`/`heroImageAlt` pointing at the retired posters (`public/articles/<slug>/hero.jpg`); the renderer ignores them on purpose. The library photo field is `photo` (+ `photoAlt`, `photoFocus`), looked up in `public/images/luke-2026/manifest.json`; a path not in the manifest fails the build. Reusing `heroImage` 500'd those six pages in dev.
- **2026-10-01 `decorate()` and elements that bring their own class.** The reveal pass used to prepend `class="rv"` to every top-level tag, which gives a transform-made `<div class="ucb ...">` two class attributes (the browser keeps the first, the block loses its class). It now folds `rv` and the stagger into the element's existing class and style. Any new transform output that is top-level gets this for free.
- **2026-10-01 A pair is exactly two titled lists in a row.** Three or more in a row (client-onboarding's six "Step N" lists, hidden-cost's four) stay a run of single blocks. Tone (deep blue / pale blue) only when the titles say before/after, works/doesn't, do/don't; Free/Paid style pairs stay neutral grey.
- **2026-10-02 Fonts on the Next site must be self-hosted.** The CSP in `next.config.mjs` allows `font-src 'self'` and Google Fonts only, so BRAND.md's Fontshare link (Satoshi, Switzer) would be blocked silently. Satoshi was already in `public/fonts/Satoshi-Variable.woff2` (tracked, unused); Switzer 400/600 copied in beside it. `@font-face` lives in `app/styles/article-blocks.css`.
- **2026-10-02 `npm run build` pings IndexNow for the live site.** `postbuild` runs `scripts/indexnow-ping.mjs`. For a branch check run `node_modules/.bin/next build` directly, which skips pre/post scripts. Potential lesson: read the npm lifecycle scripts before running build on any repo with SEO tooling.
- **2026-10-02 Full-page screenshots come back blank in the middle.** The `.rv` reveal waits for IntersectionObserver, so a fast scroll-and-shoot leaves whole sections at opacity 0, and the dev server adds its "N" badge. Shoot the production build (`next start`) with Playwright `reducedMotion: 'reduce'`; article.css already shows `.rv` under reduced motion.
- **2026-10-02 A look rule can lose to the shared `li>*` rule.** `.ucb-steps--ledger .ucb--steps .ucb__list>li>*{grid-column:2}` is (0,3,1) and beat `.ucb-steps--ledger .ucb--steps .ucb__time` (0,3,0), so the desktop chip never moved to column 3. Match the shape: `...>li>.ucb__time`.
- **2026-10-02 Round 2's target was wrong: the live site is the design.** BRAND.md and the uc-redesign-v3 mockups are old ideas Luke doesn't want. The blocks follow undercurrentautomations.com (`docs/blocks-design-notes.md`). The repo CLAUDE.md "Hard Rules" (Space Grotesk, Satoshi, 14px radius, offset shadows) describe the retired Vite design, not the live one. Potential lesson: before styling, study the shipped site, not the brand doc.
- **2026-10-02 `.body th` in article.css styles every `th` as a tracked caps label, row headers included.** A table's row headers came out as "WHAT IT CAN READ". The block base resets `tbody th` (size, tracking, case). Any new table look inherits it.
- **2026-10-02 `vertical-align` on a `writing-mode:vertical-rl` cell runs along the turned axis.** With `rotate(180deg)`, `vertical-align:bottom` put the turned column names on each cell's right edge; `top` puts them on the left, under the cell's own text.
- **2026-10-02 `background-clip:text` only paints inside the element's box.** A numeral at `line-height:.8` lost its top and foot. At `line-height:1` an Inter digit runs from about 14% to 86% of the box, so a fill of n/of maps to `14% + 72% * n / of`.
- **2026-10-02 A hero at `62vh` inside a board iframe sized to its content chases its own height.** The board CSS gives frames a fixed hero floor instead. The page itself is unaffected.
- **2026-10-02 A workings sum that doesn't add up stops the build, on purpose.** `lib/remarkArticleBlocks.js` throws `[workings] "<block title>": ...` with the numbers it got. Fix the sum in the article; don't loosen the check. Tolerance is half a unit or 1.5%, so "about $59" passes for 59.21.
- **2026-10-02 Scratchpad scripts can't import project packages by name.** Node resolves ESM from the script's own folder. Import by absolute path (`<repo>/node_modules/playwright/index.mjs`).
- **2026-10-02 `pkill -f "next start"` misses the server: it renames itself `next-server`.** A stale `next start` from an earlier build kept port 3011 and served old HTML whose CSS chunks the rebuild had deleted, so every page in the sweep came back unstyled and every hero measured wrong. Stop it by port: `kill $(lsof -tiTCP:3011 -sTCP:LISTEN)`. Potential lesson: when every page looks broken at once after a rebuild, check what holds the port before debugging CSS.
- **2026-10-02 `git rm` stages the deletion at once.** The next commit takes it, whatever was `git add`ed for that commit, and it landed in the CLAUDE.md commit. Unpushed, so the commits were redone from the branch tip. Stage a deletion in the same breath as its own commit.
- **2026-10-02 Found in the sweep, not caused by the branch:** `google-business-profile-optimisation` (body-1, body-2) and `ai-automation-for-pet-grooming` (body-1) point at `public/articles/<slug>/body-N.jpg` files that were never committed. The live site returns 400 for them. The Google Ads cost article's 300-wide SVG chart clips its own "Strong 6 / Competent 8 / Weak 12" label on a phone.
- **2026-10-02 A counter reset on a size container is lost.** `container-type:inline-size` also contains counters. With the reset on the rail's wrapper (the container), WebKit showed "1 / 0" and Chromium showed "1 / 3" on every column, because the count never advanced. Reset counters on an element inside the container (the `<table>`). It was only caught in WebKit; the Chromium screenshots only ever showed the first column.
- **2026-10-02 WebKit renders a local `next start` unstyled.** The CSP's `upgrade-insecure-requests` sends WebKit to `https://localhost` for every asset, while Chromium exempts localhost. To test Safari locally with Playwright, strip `content-security-policy` from document responses in a route. The site is fine in production, which is https.
